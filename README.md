# Telco Customer Churn Analysis

## Project Overview

This project analyzes customer churn in a telecommunications company using Python, SQL, and Power BI.

The main objective is to identify churn patterns, understand the factors associated with customer churn, and provide business insights through an interactive dashboard.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL Server
- Power BI

## Project Workflow

### 1. Data Cleaning & Exploration
Python was used to:
- Inspect the dataset
- Check data types
- Detect missing values
- Check duplicated records
- Handle missing values
- Remove unnecessary columns
- Explore customer churn patterns

### 2. SQL Analysis

SQL was used to calculate:
- Total customers
- Total churned customers
- Overall churn rate
- Churn rate by contract type
- Top churn reasons

### 3. Power BI Dashboard

The cleaned data was visualized in an interactive Power BI dashboard to analyze:
- Customer churn
- Churn rate
- Contract types
- Customer services
- Monthly charges
- Churn reasons
- Customer risk patterns

## Key Insights

The analysis helps identify:
- Which contract types have higher churn rates
- The most common reasons customers leave
- Customer segments with higher churn risk
- The relationship between customer charges and churn
